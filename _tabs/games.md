## 🏃 极速跑酷 3D

霓虹夜景跑酷。骑着坐骑穿过香港、新加坡、台北、东京、迪拜的天际线，还有熔岩峡谷和极光冰原。攒满金币进超级奖励关，金币会拼成熊猫、爱心之类的图案。

- 3 个英雄 × 3 只宠物 × 3 种坐骑
- 跳跃、二段跳、滑铲，和坐骑一起腾空、一起趴下

[▶ Play 3D](/games/runner.html){: target="_blank" } · [2D 版](/games/runner-2d.html){: target="_blank" }

## 🚇 地铁跑酷 3D

白天版三轨跑酷。躲火车、踩坡道跳上车顶、翻滚过栏，身后还有巡警在追。

- 🧲 磁铁 · 👟 超级跳鞋 · 🚀 喷气背包 · ✖2 双倍
- 🛹 滑板：撞一次不死，每局 3 块

[▶ Play](/games/subway.html){: target="_blank" }

## 🧩 休闲小游戏

不联网、不花钱，打开就玩。

- **俄罗斯方块**：现代规则——7 袋随机、SRS 旋转踢墙、暂存、5 块预览、落点阴影，T-Spin、连击、背靠背都有加分。[▶ Play](/games/tetris.html){: target="_blank" }
- **贪吃蛇大作战**：和三条电脑蛇抢食物，让它们一头撞上你的身体；撞死的蛇会变成一地豆子。也有经典单人模式。[▶ Play](/games/snake.html){: target="_blank" }
- **2048**：带滑动和合并动画，手滑了能撤销一步。[▶ Play](/games/2048.html){: target="_blank" }
